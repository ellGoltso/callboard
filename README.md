# Announcements API (Доска объявлений)
Бэкенд-часть проекта "Доска объявлений". Реализован на Django и Django REST Framework. Проект использует Docker и Docker Compose для локальной разработки и развертывания.

## ✨ Функционал

Проект предоставляет следующий набор функций:

*   **Авторизация и аутентификация пользователей** с использованием JWT токенов.
*   **Распределение ролей** между пользователями (пользователь и администратор).
*   **Восстановление пароля** через электронную почту.
*   **CRUD-операции для объявлений**:
    *   Администратор может удалять или редактировать любые объявления.
    *   Пользователи могут управлять только своими объявлениями.
*   **Система отзывов**: Пользователи могут оставлять отзывы под каждым объявлением.
*   **Поиск**: Поиск объявлений по названию в заголовке сайта.

## 🚀 Установка и запуск (Docker)

Для запуска проекта локально вам понадобятся установленные **Docker** и **Docker Compose**.

__💾 Шаг 1. Клонируем репозиторий__
<br>Склонируйте исходный код проекта:<br>
```
git clone https://github.com/ellGoltso/callboard.git
cd callboard
```

__📜 Шаг 2. Создание файла переменных окружения (.env)__

Создайте файл .env в корневой директории проекта и добавьте в него необходимые переменные.

```
SECRET_KEY=
DEBUG=


POSTGRES_DB=
POSTGRES_USER=
POSTGRES_PASSWORD=
DATABASE_HOST=
DATABASE_PORT=


EMAIL=
EMAIL_HOST_PASSWORD=
```

__📖 Шаг 3. Запуск контейнеров__

Выполните команду для сборки образов и запуска всех сервисов:

```
docker compose up --build -d
```

__📖 Шаг 4. Доступ к приложению__

Теперь ваш проект доступен по адресу: http://localhost:8000.

## ⚙️ Дополнительные команды
Все команды, которые вы обычно запускаете с python manage.py или pytest, выполняются внутри работающего контейнера web с помощью docker compose exec.

* Остановка контейнеров:
```
docker compose down
```
* Создание суперпользователя:
```
docker compose exec web python manage.py createsuperuser
```
* Запуск тестов:
```
docker compose exec web pytest
```
* Проверка покрытия кода (Code Coverage):
```
docker compose exec web pytest --cov=.
# Чтобы увидеть детальный отчет в консоли
docker compose exec web pytest --cov=. --cov-report=term-missing
```
* Проверка линтером flake8:
```
docker compose exec web flake8 .
```
